 💍 Shira Events – Dream Wedding & Event Management Website

Shira Events is a simple and elegant HTML-based event management website created to showcase wedding and celebration services. This project was developed using only HTML as a frontend practice project.

✨ Features

- Beautiful homepage
- Wedding introduction section
- Embedded YouTube video
- Premium Services section
- Event Packages table
- Online Booking Registration Form
- Easy navigation between pages
